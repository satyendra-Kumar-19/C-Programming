==================================================
RECOMMENDED C STANDARD
==================================================

1. C89/C90 (1989/1990)
2. C99 (1999)
3. C11 (2011)
4. C17 (2018)
5. C23 (2024)

RECOMMENDATION:
Learn modern, portable C using C17 as
your primary learning standard.
Explore C23 features afterwards.


==================================================
LEARNING STRATEGY
==================================================

1. Understand the WHY before the WHAT.
2. Learn concepts before memorizing syntax.
3. Write programs independently.
4. Practice logical problems regularly.
5. Understand memory and internal working.
6. Build projects after major chapters.
7. Learn debugging and error handling.
8. Revise previous concepts regularly.
9. Follow standard C programming practices.
10. Never skip pointers and memory management.

FINAL GOAL:
Become proficient in C programming,
problem-solving, memory management,
data structures, algorithms and
system-level programming.
